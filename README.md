# Student Performance Management System | Python

A Python-based system for managing student records, calculating academic results and analysing class performance.

### Features
- Calculate student totals, averages and grades.
- Determine pass/fail results.
- Generate ranked student performance reports.
- Add, update and remove student records.
- Calculate class pass percentage.
- Identify class toppers and subject-wise averages.

### Concepts Practised
Functions, nested dictionaries, lists, tuples, `*args`, `**kwargs`, sorting, data manipulation and modular programming.

### Project Structure
- `result_system.py` – Main program and task execution.
- `result_system_fns.py` – Reusable functions for result processing and student management.
